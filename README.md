### Структура проєкту
Репозиторій складається з трьох модулів:
1. Веб-застосунок на Spring Boot з чотирма ендпоїнтами + логувальний фільтр + хазелкаст нода з увімкненим Jet (для читання лог файлу)
   1. Вивід логувального фільтра в консоль вимкнений, але у файл запис відбувається
2. "Клієнт", що робить рандомний запит до веб-застосунку
3. Клієнт Hazelcast ноди, для виводу вмісту мапи
